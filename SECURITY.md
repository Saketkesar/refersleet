# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
Please do not report security vulnerabilities through public GitHub issues.

Instead, please report security issues or malicious destination URLs by emailing `kesarsaket607@gmail.com` or via GitHub Private Vulnerability Reporting.
All reports will be acknowledged within 24 hours.
