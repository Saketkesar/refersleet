### How to Become a Contributor:
1. Fork the [Refersleet repository](https://github.com/Saketkesar/refersleet).
2. Submit a new referral in `referrals/<category>/<subcategory>/<program>.md` or add your active community code to an existing referral's `alternative_codes` list.
3. Add your contributor profile markdown in `contributors/<your_username>.md`.
4. Open a Pull Request!
