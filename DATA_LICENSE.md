# RefX Open Data License

All referral records, categories, and community verification statistics in the RefX repository are made publicly available under the Open Data Commons Open Database License (ODbL) v1.0.

You are free to:
- **Share**: Copy, distribute, and use the database.
- **Create**: Produce works from the database.
- **Adapt**: Modify, transform, and build upon the database.

As long as you:
- **Attribute**: Credit RefX as the original source.
- **Share-Alike**: If you publicly use any adapted version of this database, you must also offer that adapted database under the ODbL.
- **Keep Open**: If you redistribute the database, or an adapted version of it, then you may use technological measures that restrict the work (such as DRM) only if you also distribute an equivalent copy without such measures.
