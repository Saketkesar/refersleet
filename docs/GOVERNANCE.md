# RefX Open-Source Governance

RefX operates under an open-source community governance model:
1. **GitHub is the Canonical Single Source of Truth**: All referral records and categories reside in transparent Markdown files.
2. **Transparent Data Pipeline**: The website and public API are built directly from open repository commits.
3. **Contributor Attribution**: Every contributor receives persistent, public credit on the website and API records.
4. **Independent Trust**: Verification votes and trust metrics are never altered for commercial gain.
