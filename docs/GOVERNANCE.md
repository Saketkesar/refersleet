# Refersleet Open-Source Governance

Refersleet operates under an open-source community governance model:

1. **Maintainership**: Saket Kesar (@Saketkesar) serves as project founder and lead maintainer.
2. **Transparency**: All listings, categories, and ranking algorithms are version-controlled publicly on GitHub.
3. **Decentralized Verification**: Program accuracy is maintained by real user tests and feedback.
