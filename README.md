## ⚡ Overview

**Refersleet** is a modern, transparent, community-driven open-source alternative to spammy, outdated coupon aggregators. Every program is verified for active reward terms, transparent eligibility requirements, and dual-sided benefits (both the referee and referrer receive perks).

- 🔍 **100% Verified**: Community voting ensures stale or broken referral links are immediately flagged.
- 🤖 **AI Developer Compute**: Claim free credits for LLM routing, Claude 3.5 Sonnet, GPT-4o, and Meta Muse.
- 💸 **Passive Earnings**: Monetize browser idle time and AI thinking delays with Chatwait and Pawns.app.
- ⚡ **Global CDN API**: Every program is tracked in Git Markdown and served via free static JSON feeds.

## 🚀 Public Data Feeds & Developer API

Refersleet data is 100% open, free, and accessible via static JSON feeds hosted on GitHub CDN:

```javascript
// Fetch all active verified referral offers in JavaScript
const response = await fetch(
  "https://raw.githubusercontent.com/Saketkesar/refersleet/main/generated/referrals.json"
);
const programs = await response.json();
console.log(programs);
```

- **Referrals JSON**: `https://raw.githubusercontent.com/Saketkesar/refersleet/main/generated/referrals.json`
- **Categories JSON**: `https://raw.githubusercontent.com/Saketkesar/refersleet/main/generated/categories.json`
- **Platform Stats JSON**: `https://raw.githubusercontent.com/Saketkesar/refersleet/main/generated/stats.json`
- **Contributors JSON**: `https://raw.githubusercontent.com/Saketkesar/refersleet/main/generated/contributors.json`
- **OpenAPI 3.0 Spec**: [`api/openapi.yaml`](api/openapi.yaml)
- **AI & LLM Guide (GEO)**: [`llms.txt`](llms.txt)

## ✍️ How to Submit a Program

1. **Web Form**: Go to **[saketkesar.github.io/refersleet/#/submit](https://saketkesar.github.io/refersleet/#/submit)** and click **"Copy for GitHub PR"**.
2. **Pull Request**: Add your Markdown file under `referrals/<category>/<subcategory>/<program>.md` and your contributor profile in `contributors/<username>.md`.
3. Every pull request is automatically validated against our strict JSON Schemas via GitHub Actions.
